# Imágenes de producto — JEM Store

Fotografía de producto para el catálogo ficticio de moda "JEM Store" (proyecto académico/portafolio). Las imágenes provienen de Unsplash y Pexels (ver columna "Fuente" de cada fila), son de uso libre bajo sus respectivas licencias, y fueron descargadas, recortadas (4:5, 1200x1500px) y convertidas a WEBP para almacenarse localmente en el repositorio.

Cada URL "Original" fue verificada mediante fetch real de la página antes de descargar la imagen (no se hotlinkea ningún recurso; los archivos se sirven desde `storage/app/public/products/`).

## Notas de procesamiento

- Todas las imágenes se descargaron desde el CDN oficial de su fuente (`images.unsplash.com` o `images.pexels.com`), redimensionaron/recortaron centradas a 1200x1500px (relación 4:5) y se convirtieron a WEBP (calidad ~80-85) con `cwebp`/`magick`.
- Ninguna imagen muestra logotipos de marcas comerciales (Zara, H&M, Nike, Adidas, Amazon, Shein, etc.).
- Todas las fotos son gratuitas bajo la Unsplash License o la Pexels License (uso comercial permitido, sin atribución obligatoria); se documenta el autor de todas formas por buenas prácticas.
